## What I learned

**Functions**

A function is a block of code that does one specific job. We give it a name so we can call it whenever we need it. A function can take parameters, which are the values we pass in so the code inside can use them. After it runs, the function can return a value, which is the result of what it did.

**Why clean code matters**

Writing clean code makes life easier for us and for other people who work on the code. Some reasons are:

- It's easier to read and understand
- We can reuse parts of the code instead of writing them again
- It's easier to maintain and update later
- It helps a lot when debugging
- It makes working with other programmers smoother
