# TP03 - Hugging Face and Model Selection

## Teacher's questions and my answers

**1. What is Hugging Face?**

Hugging Face is an AI company, and they have a website where people can share AI models. It's kind of like GitHub but for AI. On the site we can search for models that other people already made, then download them or use them in our own project. There are also datasets we can use, and we can even train our own model and upload it there.

**2. What is model selection in LLM?**

Model selection means picking which LLM we should use for our task. There are a lot of models, so we can't just pick any one. We need to think about a few things:

- How big the model is (bigger models need a stronger computer)
- How good it is at the task we want
- How much it costs to use
- The license (some models can't be used for business)
- If we can actually get it (some are open source, some are only through an API)
